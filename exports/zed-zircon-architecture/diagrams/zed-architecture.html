Key Architectural Trait: Unlike Electron editors that bridge web technologies across process boundaries via IPC, Zed runs everything in native Rust compiled directly to machine code. Background threads hold immutable SumTree snapshots of text, syntax trees, and worktrees to calculate syntax highlighting, git diffs, and LSP diagnostics concurrently without ever blocking the 120 FPS GPU render loop.
