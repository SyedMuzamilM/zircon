## Zircon

- The measured wrap tree indexes source bytes, logical lines and visual rows. The earlier 1 MiB result predates this index. In the new 1 MiB workload with Git, syntax and LSP enabled, each wrapped burst reshaped 20 lines across 20 edits. Median p95 input-to-submission was 9.42 ms with wrapping and 10.19 ms without wrapping, with overlapping ranges. [Wrap index commit](https://github.com/SyedMuzamilM/zircon/commit/352d50e) · [Benchmark and raw evidence](../../docs/benchmarks/editor-2026-11-20-wrap-index/README.md)
- The Rust grammar worker now retains a highlighter across successive requests and reuses its Tree-sitter query cursors. The worker still runs in a separate process. [Cursor reuse commit](https://github.com/SyedMuzamilM/zircon/commit/7ec23e5)
- The architecture diagrams still describe Zircon's rope-backed snapshots, committed-frame fallback and separate extension worker. [Window runtime design](../../docs/design/runtime.md)
- The local editing follow-up verified clean external reload through two panes and the existing language session. Native checks found open issues in grapheme handling and the macOS accessibility tree. [Document events](../../docs/progress/2026-11-07-document-events.md#november-20-follow-up) · [Native input and accessibility](../../docs/progress/2026-11-20-native-input.md)
